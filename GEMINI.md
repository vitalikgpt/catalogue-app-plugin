# Catalogue App

Tools of the `catalogue-app` MCP server work with Telegram:

- `create_bot` — a link that creates the user's own Telegram bot in one tap (no @BotFather, no server, hosted free by @catalogue_app). Check `list_bot_templates` first.
- `create_pack` — a link to make a custom emoji or sticker pack from the user's media.
- `search_apps`, `search_channels`, `search_packs` — find mini apps, bots, channels, chats and packs.
- `telegram_bot_api_guide` — notes on managed bots, Mini Apps, packs, Stars payments, webhooks, limits.

Always hand the user the returned link: creation finishes in Telegram.
