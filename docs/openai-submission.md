# OpenAI plugin submission

Upload `dist/catalogue-app-openai.zip` at platform.openai.com/plugins after the organization is verified.

## Positive test prompts (the plugin should be used)

1. Make me a Telegram support bot for my online store.
2. Create an anonymous questions bot for my Telegram channel.
3. Find Telegram emoji packs with cats.
4. Which Telegram channels write about TON? Show the biggest ones.
5. Is there a Telegram mini app for splitting bills?

## Negative test prompts (the plugin should not be used)

1. Write a haiku about autumn.
2. How do I reset my WhatsApp password?
3. Convert 30 degrees Celsius to Fahrenheit.

## Walkthrough video script (≈60 s)

1. In ChatGPT, ask "Make me a Telegram support bot for my online store."
2. Show the reply with the link; open it on a phone with Telegram; Telegram's create-bot sheet appears; confirm; the new bot answers /start.
3. Ask "Find Telegram emoji packs with cats" — show the list; tap an add link; Telegram offers to add the pack.
4. Ask "Which Telegram channels write about TON?" — show channels with subscriber counts.
