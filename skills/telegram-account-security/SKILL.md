# Account security

| Task | Where |
|---|---|
| Two-step verification (cloud password) | Settings → Privacy and Security → Two-Step Verification. Add a recovery email |
| See devices, log out everywhere | Settings → Devices → "Terminate all other sessions" |
| Passcode lock on this device | Settings → Privacy and Security → Passcode Lock |
| Change phone number | Settings → tap the number → Change Number |
| Delete the account automatically | Settings → Privacy and Security → "Delete my account if away for" |
| Delete the account now | https://my.telegram.org/deactivate (login code comes to Telegram) |

## After a hack

1. Settings → Devices → terminate every session you don't recognise
   (sessions younger than 24 hours may not be terminable from a new device —
   then wait and retry).
2. Turn on Two-Step Verification, or change its password and recovery email.
3. Check Settings → Privacy and Security → Active Websites; disconnect unknown.
4. Warn contacts: the attacker may have messaged them.

## "I can only message mutual contacts"

That is a spam restriction. Open @SpamBot and follow its answer — it says
whether the account is limited and until when, and lets you appeal.

## Deleted messages

Deleted messages cannot be restored by users. Group admins can see recently
deleted messages for 48 hours in Recent Actions (admin log).
