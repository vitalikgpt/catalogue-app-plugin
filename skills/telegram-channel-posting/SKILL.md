# Channel posting

## With @catalogue_app

1. Open `https://t.me/catalogue_app?start=posts` (or send `/posts`).
2. Connect the channel — the bot asks to be added as an admin with the right
   to post.
3. Send the post text or media, add URL buttons, then publish now or schedule.

Autoposting: in the same section add a source — an RSS/Atom feed, a YouTube
channel, or a public Telegram channel (`t.me/s/<name>`). New items are checked
every 10 minutes and posted to your channel. Up to 5 channels and 10 sources.

## Without a bot

Telegram can schedule a message natively: type the post, then long-press the
send button → "Schedule message". URL buttons under a post need a bot.
