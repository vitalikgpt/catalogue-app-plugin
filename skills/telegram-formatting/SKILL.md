# Text formatting

## Select and format (all apps)

Type the text, select it, then use the menu that appears (on phones:
"Format" or the ⋮ in the selection menu; on desktop: right-click → Formatting)
→ Bold, Italic, Underline, Strikethrough, Spoiler, Monospace, Quote, Link.

## Markdown shortcuts while typing

| Result | Type |
|---|---|
| **bold** | `**text**` |
| *italic* | `__text__` |
| ~~strikethrough~~ | `~~text~~` |
| hidden spoiler | `\|\|text\|\|` |
| `monospace` | `` `text` `` |
| code block | three backticks before and after |

Desktop shortcuts: Ctrl/⌘+B bold, Ctrl/⌘+I italic, Ctrl/⌘+U underline,
Ctrl/⌘+Shift+X strikethrough, Ctrl/⌘+Shift+P spoiler, Ctrl/⌘+Shift+M
monospace, Ctrl/⌘+K link.

## Disappearing photo or video

In a private chat attach a photo or video, then tap the timer (or long-press
send → "Send as one-time view" / set a timer). The recipient can open it once;
it then disappears. Screenshots are blocked on phones for such media.

## Spoiler on media

When attaching a photo or video, open its menu (⋮ or long-press) → "Hide with
spoiler" — it is blurred until tapped.
